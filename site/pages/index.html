A report goes in, an issue comes out

Your users send what they saw. FeedbackBee files it in the repo you pick, labeled and with the media attached, and keeps who sent it to itself.

  • Goes to GitHub

    The note, screenshots, replays and voice notes, plus the OS, device, app version, screen size and browser.

  • Stays in FeedbackBee

    The reporter’s email, name and user id, the page they were on, and any metadata you attach. The issue links back to it instead.

Running in about five minutes

One Worker with D1 and R2. It fits in Cloudflare’s free tier, and your GitHub token never leaves it.

  1. Deploy

    The Deploy button, or one command. The database and storage are created for you; the only secret is your GitHub token.

  2. Add the widget

    One script tag on the web, one call on Android. Extras load only when someone uses them.

  3. Triage in GitHub

    Reports arrive as labeled issues in the repo you pick. Reply, label and close as usual.

Deploy

pnpm deploy:worker
pnpm exec wrangler secret put GITHUB_TOKEN

Web

<script src="https://your-bee.workers.dev/embed.js"
  data-project="myapp" async></script>

Android

FeedbackBee.init(this, projectId = "myapp", endpoint = "…")
FeedbackBee.open() // or shake
