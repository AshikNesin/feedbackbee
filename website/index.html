User feedback that lands in GitHub issues

A tiny widget for your web and Android apps. Users grab a screenshot, mark it up or record what happened, and you get a labeled issue. Self-hosted on Cloudflare’s free tier.

Features

Everything a good bug report needs, nothing your users have to learn

One-click screenshots

Captures the page they’re on, right in the browser. No “choose a tab” dialog.

Quick annotations

Arrows, boxes, highlighter, text, step numbers and pixelate for anything private.

Session replay

Record the page as they reproduce the bug, without a permission prompt. Passwords stay masked.

Voice notes

When typing it out is slower than saying it.

Straight to GitHub issues

Labeled by type, with the page URL, browser details and media linked. Triage where you already work.

Android SDK

Kotlin, no heavy dependencies. Shake to send feedback from any screen.

Get started

Running in about five minutes

One Worker with D1 and R2. It fits in Cloudflare’s free tier, and your GitHub token never leaves it.

Deploy

The Cloudflare button provisions the database and storage, then deploys.

pnpm exec wrangler secret put GITHUB_TOKEN

Embed

Add one script tag to your app. It loads extras only when someone uses them.

<script src="https://your-bee.workers.dev/embed.js"
  data-project="myapp" async></script>

Triage

Feedback shows up as issues in the repo you connect. Reply, label and close as usual.

FeedbackBee.init(this, "myapp", endpoint)
